# Design Decision Log

Date: 2026-08-19

## Accepted Direction

Direction A, **Data Observatory / 数据观测工作台**, was selected by the user.

The implementation should preserve these visual decisions:

- cool white and blue-gray coordinate grid;
- circular portrait as the identity anchor;
- handwritten English signature used sparingly;
- blue analysis route connecting question, method and decision;
- real dashboard and research images as the primary visual evidence;
- open rails and indexed rows instead of a generic nested card grid;
- mobile reordering into a readable single-column flow.

The production implementation must not carry over the existing dark neon palette, eye graphic, animated orbit cards, runtime CDN icons or fabricated metrics.

## Intentional Deviation From Reference

The reference site uses personal social, music, visitor and character modules. Those are intentionally replaced by real analytics capabilities, project types, methods and evidence paths. No reference-site characters, copy, photos, logo or proprietary fonts are used.
